# Market Monitor (starter)
iPad Safariで閲覧できる、日本株・米国株の市場環境ダッシュボードです。

## 起動
Python 3.11+
```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```
ブラウザで `http://localhost:8000` を開きます。iPadから同じWi-Fi内でPCのIPアドレス:8000へアクセスすることもできます。

## クラウド公開
Render / Railway / Fly.io等のPython対応ホスティングへデプロイし、HTTPSを有効にしてください。iPad SafariからURLを開き「共有」→「ホーム画面に追加」でアプリ風に利用できます。無料プランはスリープ・実行時間・通信量等の制限があり得ます。

## データソースと制約
- 株価・指数: yfinance経由のYahoo Finance公開データ。非公式アクセスであり、遅延、欠損、利用条件変更の可能性があります。商用・高頻度用途には使わないでください。
- 米国経済: FRED API。`FRED_API_KEY`環境変数を設定するとDGS10、DGS2、HYスプレッド、VIXを追加取得します。キーなしでも株価ベースの簡易表示は動きます。
- 日本の外国人投資家売買: JPX等の公表CSVを `/api/foreign-flows` へアップロードする設計。列の意味・単位を確認してから利用してください。現状は自動取り込みではありません。
- 米国セクター: セクターETFの価格騰落率を表示。ETFの純資金流入額ではありません。
- 日本のセクター別フロー: このスターターでは未実装。信頼できる業種別売買・ETFフローのデータ契約/データソースが必要です。
- スコア: トレンド、VIX、米国10年債利回りによる暫定的な代理指標。市場全体の騰落銘柄数やA/Dラインを完全には反映しません。
- バックテスト: 1306.T / SPYの200日移動平均トレンド戦略。配当、税、手数料、スリッページ、売買停止等を完全には反映しない簡易検証。未来の成績を保証しません。
- AIレポート: 現状はルールベースのレポート。LLMによる分析はAPIキーと追加実装が必要です。

## 次の本番化ステップ
1. JPX CSVの公式フォーマットを確定し、週次自動取得と単位検証を実装。
2. 日本の市場幅（値上がり/値下がり、新高値/新安値、200日線上比率）を追加。
3. 米国・日本セクターETFのフローを公式/契約データで補完。
4. データ保存（PostgreSQL等）と欠損・鮮度チェックを追加。
5. 本番用の認証、APIキー管理、ログ、アラート配信を追加。
6. 過去10年バックテストを配当込みデータで再検証し、ウォークフォワード検証とコストを加味。

## 日次自動更新（GitHub Actions）
GitHubへこのプロジェクトをpushすると、平日07:30 JSTを目安にスナップショットを取得して `data/dashboard.json` を更新します。Actionsの実行にはGitHub側のActions有効化と書き込み権限が必要です。スケジュール実行は混雑等で遅延する場合があります。

任意でGitHubリポジトリのSecretsに `FRED_API_KEY` を登録するとFRED系列も取得します。`OPENAI_API_KEY` と任意の `OPENAI_MODEL` を登録すると日次レポート生成時にAI要約を使います（API利用料が発生する場合があります）。キーをソースコードに直接書かないでください。
